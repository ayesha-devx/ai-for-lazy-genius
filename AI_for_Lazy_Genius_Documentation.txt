PROJECT OVERVIEW
-------------------------------------------------------------
"AI for Lazy Genius" is a premium, state-of-the-art MERN platform designed for high-level technical thought leadership. It combines a "SaaS-grade" visual identity—characterized by purple-themed glassmorphism and fluid micro-animations—with deep Artificial Intelligence integration. The platform caters to a community of experts who create, consume, and distill complex engineering knowledge.

=============================================================
                     CORE TECH STACK
=============================================================

FRONTEND:
- Framework: React.js 18 (Vite-powered for high-performance HMR)
- Styling: Tailwind CSS (Custom Slate-to-Purple theme)
- Animations: Framer Motion (Fluid transitions & micro-interactions)
- State Management: Zustand (Lightweight, proxy-based store)
- Icons: Lucide React (Clean, modern iconography)
- Routing: React Router DOM 6 (Nested layouts & dynamic pathing)
- Markdown: React-Markdown with remark-gfm (Full GFM support)

BACKEND:
- Runtime: Node.js (v18+)
- Framework: Express.js (REST API architecture)
- Database: MongoDB Atlas (Cloud-native data persistence)
- AI Engine: Google Generative AI SDK (Direct integration with Gemini models)
- Auth: JWT (JSON Web Tokens) with HttpOnly Cookies & Bcrypt hashing
- File Management: Multer (Local buffers) & Cloudinary (Persistent storage)

=============================================================
                PREMIUM FEATURES & CAPABILITIES
=============================================================

1. THE EXPERT PERSONA SYSTEM
-------------------------------------------------------------
The platform is designed for specialized engineering roles:
- Ayesha Topiwala: Senior AI/ML Engineer (Content focus: Neural Nets, Transformers, LLMs)
- Tanisha: Senior Frontend Architect (Content focus: Micro-Frontends, Wasm, UX Perf)
- Arjun: Senior Cloud Architect (Content focus: Kubernetes, Golang, DevOps, SRE)

2. THE BRAIN BANK (AI SUMMARIZATION)
-------------------------------------------------------------
- Functionality: A "sticky" floating AI button on every blog post.
- Action: Uses Google Gemini AI to analyze article content and generate a "Lazy Summary"—a distilled, bulleted version for fast consumption.
- Storage: Summaries can be saved to a personal "Brain Bank" (Notes page) for long-term retention.

3. VOICE INTELLIGENCE (READER)
-------------------------------------------------------------
- Functionality: Integrated Voice Reader on the blog detail page.
- Capability: Converts long-form technical Markdown into clear speech, allowing users to consume deep-dives hands-free.

4. SMART COVER PICKER (🥇 CURATED LIBRARY)
-------------------------------------------------------------
- Logic: Abandoned generic stock APIs for a premium, local curated library of 21 high-end technical visuals (AI heads, server farms, neural circuits).
- Choose For Me: A deterministic engine that matches blog titles with the most relevant technical masterpiece.
- Smart UX: Auto-suggests a cover once the blog title reaches a significant character threshold.

5. DETERMINISTIC AVATAR SYSTEM
-------------------------------------------------------------
- Feature: "One User, One Icon" consistency.
- Implementation: Uses a name-based deterministic hash to assign stable, unique avatars to users across the entire platform (Home, Feed, Profile, Dashboard).

6. AI WRITER STUDIO (AUTHOR HUB)
-------------------------------------------------------------
- Functionality: A hidden studio panel in the editor.
- Customization: Select Topic, Tone (Professional/Technical), and Level.
- Generation: Directly interfaces with Gemini AI to produce structured, Markdown-ready technical blogs in under 10 seconds.

=============================================================
               PAGES & INTERFACE ARCHITECTURE
=============================================================

1. DASHBOARD ( /dashboard )
-------------------------------------------------------------
- Real-time Analytics: Dynamic grid showing Published count, Drafts, Likes, and Comments.
- Content Management: Tabbed view for managing drafts and live posts with instant Edit/Delete capabilities.

2. BLOG DETAIL ( /blog/:id )
-------------------------------------------------------------
- UI: Full-width technical covers, reading progress bar, and dynamic Table of Contents.
- Engagement: Inline liking, bookmarking, and a slide-out real-time Comment Section.

3. PROFILE ( /profile )
-------------------------------------------------------------
- Design: Glassmorphic cards with animated "Edit Profile" transitions.
- Details: Professional titles, AI-generated bios, social links, and skills tagging.
